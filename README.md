# Código da Ilha – Edição Free Fire

## Sobre o Projeto

Código da Ilha – Edição Free Fire é um projeto desenvolvido em linguagem C com o objetivo de simular o gerenciamento de uma mochila contendo componentes coletados durante uma missão de fuga de uma ilha.

O projeto foi criado para praticar conceitos fundamentais de Estruturas de Dados e Algoritmos, utilizando vetores, structs, enumerações, ordenação e busca binária. O usuário pode cadastrar, remover, visualizar, organizar e localizar componentes armazenados na mochila.

## Funcionalidades

- Cadastro de componentes na mochila.
- Remoção de componentes pelo nome.
- Listagem completa do inventário.
- Ordenação dos componentes por:
  - Nome
  - Tipo
  - Prioridade
- Busca binária por nome.
- Controle de capacidade máxima da mochila.
- Exibição da quantidade de comparações realizadas durante a ordenação.

## Como Executar

### Compilando o Código-Fonte

```bash
gcc Codigo_da_Ilha.c -o Codigo_da_Ilha
```

Para executar:

```bash
./Codigo_da_Ilha
```

No Windows:

```bash
Codigo_da_Ilha.exe
```
